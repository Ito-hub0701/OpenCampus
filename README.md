# OpenCampus

Unityで制作した、オープンキャンパス向けのリアルタイム画像処理デモです。

Webカメラ映像に対してリアルタイムで画像処理を行い、
「コンピュータが画像をどのように見ているか」を体験できる展示を目指しています。

---

# デモ内容

Webカメラ映像に対して、以下の画像処理をリアルタイムで適用できます。

- NORMAL
  - 通常映像

- GRAY
  - グレースケール化（白黒化）

- THRESHOLD
  - 二値化処理

- INVERT
  - 色反転

- RED / GREEN / BLUE
  - 特定色の強調表示

- EDGE
  - 隣接画素との差分を利用した簡易輪郭抽出

# 展示コンセプト

この展示では、
「コンピュータは画像をそのまま見ているのではなく、数字として解析している」
という点を高校生向けに分かりやすく伝えることを目的としています。

特に、以下のような画像処理の基礎を体験できます。

- グレースケール
- 二値化
- 色抽出
- 輪郭抽出
- RGB成分の違い

オープンキャンパス当日は、RGB色カードなどを用いて、
実際に色検出を体験してもらう想定です。

# 実行方法

## 1. プロジェクトを開く

Unity Hubから本プロジェクトを開いてください。

---

## 2. シーンを開く

`Main` シーンを開きます。

---

## 3. 実行

Unity上部の Play ボタンを押すと、Webカメラ映像が表示されます。

---

# Build時の注意

macOSでは、Webカメラを使用する場合に Camera Usage Description の設定が必要です。

以下を設定してください。

`Edit -> Project Settings -> Player`

`Camera Usage Description`

例:

```text
画像処理デモのためにカメラを使用します。
```
